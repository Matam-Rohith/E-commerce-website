# Morrow � E-commerce Website

Premium college-project storefront built with Next.js App Router, TypeScript, Tailwind CSS, and a clean component architecture. Stripe payments are intentionally excluded.

## Run locally
`npm install` then `npm run dev`; open http://localhost:3000.

## Pages
Home, shop, product details, cart, about foundation, contact foundation, and responsive mobile navigation.

## Deploy
Import into Vercel. This initial college version has no payment secrets or external service requirements.
